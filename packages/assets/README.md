# @poc-hierarchical/assets

Canonical asset catalog and backend build pipeline for the hierarchical navigation POCs.

## Catalog

The catalog is the single source of truth for every canonical asset. It lives in [`src/catalog.ts`](./src/catalog.ts) and is validated against [`src/schema.json`](./src/schema.json) by `npm run validate`.

## Build pipeline

The asset build pipeline transforms canonical source files into backend-specific artifacts under `dist/`.

### 3D source layout

Place 3D source assets in `sources/3d/`:

```text
packages/assets/sources/3d/
└── <asset-id>.glb
```

For each catalog entry, the pipeline looks for `sources/3d/<id>.glb` and copies it to `dist/3d/<id>.glb`. Any additional `.glb` files are also copied to `dist/3d/`.

### 2D export

2D SVG sprites and isometric PNG renders are generated by the build pipeline from [`src/render-2d.ts`](./src/render-2d.ts). For every catalog entry the pipeline produces:

- `dist/2d/svg/<id>.svg`
- `dist/2d/sprites/<id>.png`

The generator consumes the canonical palette and isometric face-shading rules from `docs/palette.json`. Scene and object SVGs reuse the existing canonical artwork where available and procedural illustrations for the remaining assets.

### Spritesheet

`dist/2d/sprites/spritesheet.json` is generated automatically with one entry per sprite. The frame data uses the real width and height of each PNG; it provides the manifest consumers need to build a real packed spritesheet later.

### Missing 3D assets

If a 3D source file is missing for a catalog asset, the build emits a warning but continues and exits successfully. This lets the pipeline be wired and run before all 3D source assets have been authored.

## Scripts

| Script | Description |
| --- | --- |
| `npm run build` | Compile the package TypeScript sources. |
| `npm run build:assets` | Compile and run the asset build pipeline. |
| `npm run clean` | Remove `dist/`. |
| `npm run validate` | Validate the catalog against the JSON schema. |

From the repository root:

| Script | Description |
| --- | --- |
| `npm run assets:build` | Build the asset pipeline artifacts. |
| `npm run assets:clean` | Clean the asset pipeline artifacts. |
